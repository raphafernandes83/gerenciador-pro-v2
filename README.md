# Gerenciador PRO — Lista de interessados

Landing page pública para captar futuros compradores e revendedores.

## Endereço público

https://raphafernandes83.github.io/gerenciador-pro-v2/

## Rastreamento por grupo

Use links como:

`https://raphafernandes83.github.io/gerenciador-pro-v2/?origem=grupo-traders-brasil`

O valor informado em `origem` será salvo junto ao cadastro depois que o backend do Google Sheets for autorizado e configurado em `config.js`.

## Armazenamento

O código do backend Google Apps Script está no pacote original do projeto. Depois de publicado como Aplicativo da Web, a URL terminada em `/exec` deve ser inserida em `config.js`.
